Çekirdek Mimari

Tarayıcı sekmeleri arasında kaybolmadan tedarik planla.

01 / DOM Adaptörleri JSON-LD + TL Parser

Sayfadan Tek Tıkla Ürün Yakalama & Sağ Tık Menüsü

Desteklenen 6 mağazada ürün sayfasındayken başlık, fiyat, stok durumu ve SKU bilgisini doğrudan BOM'a çekin. Herhangi bir GitHub README veya datasheet'te metin seçip sağ tıkla aktif listeye ekleyin.

02 / Çift Yönlü Köprü KiCad • EasyEDA

bom-sourcing JSON & EDA CSV Desteği

Agent skill çıktısı olan 10 alanlı JSON veya KiCad/EasyEDA CSV dosyalarını içe aktarın. Fiyat ve stok kanıtları ham BOM alanlarına karışmadan ayrı tutulur.

03 / Graceful Degradation 5 Dil • OKLCH

Sunucusuz Çevrimdışı Çalışma Modu

Yerel robo-api sunucusu kapalıyken bile eklenti kilitlenmez; yerel BOM düzenleme ve 6 mağazada kademeli ?q=... arama sekmeleri açma çalışmaya devam eder.

04 / Sepet & Onay Disiplini No Auto-Checkout

Kargo Eşiği Dahil Tek Mağaza vs. Bölünmüş Sepet

Belirsiz (partial / ambiguous) eşleşmeler kullanıcı açıkça onaylamadan kilitlenmez. Seçilen senaryodaki mağaza ürünleri kontrollü gruplar halinde yeni sekmelerde açılır.

bom-sourcing Sözleşmesi

Saf 10 Alanlı BOM JSON Çıktısı

Eklenti içinde topladığınız mağaza URL'leri ve anlık fiyat gözlemleri ayrı candidates yapısında tutulur. Dışa aktardığınız JSON dosyası bom-sourcing skill şemasını asla bozmaz.

  • status: confirmed | inferred_required | optional_or_assumed
  • match_confidence: exact | partial | ambiguous | unmatched
  • stock_status: in_stock | low_stock | out_of_stock | unknown
bom-export.sample.json 
[
  {
    "raw_name": "HX711",
    "canonical_name": "HX711 Yük Hücresi Amplifikatör Modülü",
    "quantity": 1,
    "status": "confirmed",
    "source_files": ["src/scale.cpp:15-29", "include/pins.h:5-6"],
    "constraints": {
      "interface": "2-wire serial (DT, SCK)",
      "adc": "24-bit"
    },
    "search_queries": ["HX711 modül", "HX711 load cell amplifier"],
    "match_confidence": "exact",
    "stock_status": "in_stock",
    "notes": "Kullanıcı tarafından onaylandı; load cell gövdesi ayrıca kontrol edilmeli."
  }
]

2 Dakikada Chrome'a Yükle

Chrome Web Mağazası incelemesi tamamlanana kadar en güncel imzalı paketi GitHub Releases üzerinden indirip geliştirici moduyla doğrudan kurabilirsiniz.

Latest Release (.zip) Gizlilik Politikası
ADIM 01

Paketi İndir & Çıkar

GitHub Releases sayfasından en son bom-tr-*.zip dosyasını indirin ve bir klasöre çıkarın (veya kaynaktan make build çalıştırın).

ADIM 02

Geliştirici Modunu Aç

Chrome adres çubuğuna chrome://extensions yazın, sağ üst köşeden Geliştirici modu anahtarını aktif hale getirin.

ADIM 03

Paketlenmemiş Öğe Yükle

Paketlenmemiş öğe yükle butonuna tıklayıp çıkardığınız klasörü seçin. Araç çubuğundan veya Ctrl+Shift+B ile Side Panel'i açın.

$ git clone https://github.com/AtaCanYmc/bom-tr.git && cd bom-tr && make install && make build
